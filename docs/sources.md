# 퀴즈 참고 자료 기록

현재 제공된 원본 README와 코드에는 참고 자료의 구체적인 URL·서지정보가 포함되어 있지 않습니다. 출처를 임의로 추정하거나 가공하지 않았습니다. 실제 제출 전 문제별로 확인한 원문 자료를 아래 형식으로 보완하세요.

| 문제 번호 | 주제 | 확인한 자료의 정확한 제목·저자·발행처·URL | 자료가 뒷받침하는 내용 |
|---:|---|---|---|
| 1~4 | 양면숙나 및 히다 지역 전승 | 제출자가 원문 확인 후 기입 | 『일본서기』의 기록과 지역 전승의 차이 |
| 5~6 | 음양도·음양료 | 제출자가 원문 확인 후 기입 | 음양도의 영역과 관료 조직 |
| 7~8 | 식신 | 제출자가 원문 확인 후 기입 | 시대·문헌에 따른 의미의 차이 |
| 9~12 | 작가 인터뷰, 불교·일본 신격 | 제출자가 원문 확인 후 기입 | 인터뷰 보도 및 종교적 개념 |

자료를 찾을 때는 1차 자료(고전 문헌 원문·공식 인터뷰)를 우선하고, 번역·보도·학술 연구를 구분해 기록합니다. 작품 해석이나 팬덤 추측은 공식 발언과 동일한 수준의 근거로 표시하지 않습니다.
