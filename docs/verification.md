# 검증 절차 및 결과 기록 양식

## 자동 테스트

프로젝트 루트에서 실행:

```bash
python -m unittest discover -s tests -v
```

테스트는 기본 퀴즈 12개, 정답 판정, 잘못된 선택지 수, JSON 저장/불러오기, 구버전 스키마 이행, 입력 경계값(빈 값·문자·범위 초과·공백), 메뉴 통합 흐름, 백업 복원, 손상 JSON 복구를 확인합니다.

기본 퀴즈 수를 별도로 확인하려면:

```bash
python -c "from quiz_game import QuizGame; print('기본 퀴즈 수:', len(QuizGame.default_quizzes()))"
```

기대 결과: `기본 퀴즈 수: 12`

## 수동 확인 항목

- [ ] 메뉴 1에서 퀴즈를 끝까지 풀고 결과/최고점수가 저장되는가?
- [ ] 메뉴 2에서 새 문제를 등록하고 재실행 후에도 남는가?
- [ ] 메뉴 3에서 전체 목록과 문제 수가 표시되는가?
- [ ] 메뉴 4에서 최고 점수가 표시되는가?
- [ ] 메뉴 5에서 저장 성공/실패 메시지가 표시되는가?
- [ ] 메뉴 6에서 백업 복원 여부를 확인하고 정상 복원하는가?
- [ ] `logs/quiz_game.log`에 저장/복구 기록과 오류 코드가 남는가?
