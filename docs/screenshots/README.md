# 제출 스크린샷 안내

아래 파일은 실제 실행 환경에서 캡처해 이 폴더에 저장합니다. 이 ZIP에는 사용자의 PC·터미널에서 직접 캡처해야 하는 이미지가 포함되어 있지 않습니다. 예시 이미지를 실제 증빙처럼 만들지 않았습니다.

| 파일명 | 캡처할 내용 | 권장 절차 |
|---|---|---|
| `menu.png` | 프로그램 시작과 전체 메뉴(1~6) | `python main.py` 실행 직후 |
| `play.png` | 실제 퀴즈 문제, 정답/오답, 최종 결과 | 메뉴 1 선택 후 끝까지 진행 |
| `add_quiz.png` | 새 문제 추가 및 저장 성공 | 메뉴 2에서 문제·선택지·정답 입력 |
| `score.png` | 최고 점수 화면 | 메뉴 4 선택 |
| `backup.png` | 백업 복원 메뉴 또는 복원 성공 | 데이터 저장을 2회 이상 한 뒤 메뉴 6 선택 |
| `git-log.png` | 브랜치 그래프와 커밋 이력 | `git log --oneline --graph --decorate --all` |
| `git-remote.png` | 원격 저장소 URL | `git remote -v` |
| `git-push.png` | push 성공 결과 | 실제 `git push` 실행 결과 |

캡처 이미지에는 계정 비밀번호, 토큰, 개인 정보가 보이지 않도록 확인한 뒤 제출합니다.
